# Build and verify the Debian ARM64 rootfs

## Objective

Produce a checksummed Debian 13 ARM64 root filesystem for the Nord without
executing untrusted third-party bootstrap scripts on the phone.

The workflow copies a rootfs generated by Debian's `debuerreotype` pipeline at
a pinned Git commit and verifies the published archive checksum before
uploading it as a GitHub Actions artifact.

## Sources of truth

- `configs/linux/rootfs.env`: Debian release, snapshot, upstream commit and
  rootfs checksum
- `.github/workflows/build-debian-arm64-rootfs.yml`: fetch, verification and
  artifact assembly

## Run the build

```bash
gh workflow run build-debian-arm64-rootfs.yml

run_id=$(
  gh run list \
    --workflow build-debian-arm64-rootfs.yml \
    --limit 1 \
    --json databaseId \
    --jq '.[0].databaseId'
)

gh run watch "$run_id" --exit-status
```

## Download and verify

```bash
artifact_dir="artifacts/debian-rootfs-$run_id"
mkdir -p "$artifact_dir"

gh run download "$run_id" \
  --name "debian-${run_id}-arm64-rootfs" \
  --dir "$artifact_dir"

(
  cd "$artifact_dir"
  shasum -a 256 -c SHA256SUMS
)

cat "$artifact_dir/ROOTFS-MANIFEST.txt"
```

Every checksum must report `OK`. Confirm that `control_plane_commit` identifies
the intended repository commit and that the upstream commit and rootfs hash
match `configs/linux/rootfs.env`.

## Artifact contents

- `debian-13.7-arm64-rootfs.tar.gz`: root filesystem to extract on the phone
- `PACKAGES.tsv`: package inventory from the Debian dpkg database
- `requested-rootfs.env`: pinned build inputs
- `ROOTFS-MANIFEST.txt`: resolved provenance and repository commit
- `SHA256SUMS`: artifact integrity record

## Exit criterion

The workflow succeeds, all checksums pass, and the manifest matches the
committed input configuration. Extraction and chroot mounting belong to the
next runbook.
